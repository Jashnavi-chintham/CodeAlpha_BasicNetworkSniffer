# Basic Network Sniffer

## Description
This project is a Python-based network sniffer developed using Scapy. It captures and analyzes live network packets.

## Features
- Captures live network traffic
- Displays source IP address
- Displays destination IP address
- Detects TCP and UDP protocols
- Shows packet payload data

## Technologies Used
- Python
- Scapy
- Npcap
- VS Code

## How to Run

```bash
python sniffer.py
```

## Output
The program captures packets and displays network information in real time.
